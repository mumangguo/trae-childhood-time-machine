# 童年时光机 · 我的梦想档案馆
## 产品需求文档（PRD）
**适配活动：** 六一「童年梦想 × TRAE」
**技术栈：** 前端(HTML+Bootstrap5+jQuery+Font-awesome) + 后端(Node.js+Express+Sqlite) + 部署(Vercel)
**UI风格：** 黑绿像素风（严格对齐 TRAE.ai 官网视觉）
**核心定位：** 一个可存储、展示、分享童年梦想的轻量化治愈向网站

---

## 一、产品概述
1. **一句话定位**
用TRAE开发一台「童年时光机」，用户可以写下自己的童年梦想，生成专属梦想卡片，永久存档、公开展示、一键分享。
2. **目标**
- 完美贴合六一儿童节主题
- 贴合「童年梦想 × TRAE」活动主题
- 视觉风格统一TRAE官网，辨识度高
- 轻量、可快速开发、直接部署Vercel上线
3. **用户群体**
所有TRAE社群用户、大朋友、小朋友

---

## 二、核心功能需求
### 1. 首页 / 时光机欢迎页
- 像素风大标题：童年时光机 · 我的梦想档案馆
- 副标题：小时候的梦想，现在由TRAE帮你珍藏
- 两个主入口：【写下我的梦想】【查看所有梦想墙】
- 底部：TRAE品牌标识 + 六一快乐标语
- 像素风动画：纸飞机、星星、电波流动效果

### 2. 梦想发布页（核心功能）
表单包含：
- 昵称（必填，最多10字）
- 我的童年梦想（必填，文本框，5-100字）
- 现在我用TRAE可以______（选填，5-50字）
- 提交按钮（像素风格）
提交成功后：
- 跳转到**个人梦想卡片页**
- 提示：梦想已存入时光机！可分享

### 3. 梦想卡片页（个人成果页）
展示内容：
- 像素风卡片框架（黑绿TRAE风格）
- 昵称
- 童年梦想内容
- TRAE实现句
- 发布时间
- 唯一分享链接
- 两个按钮：【保存图片】【返回首页】

### 4. 梦想墙 / 公开档案馆
- 卡片流布局（响应式）
- 所有用户发布的梦想卡片公开展示
- 按时间倒序：最新梦想排在最前
- 无刷新加载 / 分页加载
- 每条卡片可点击查看详情

### 5. 后端功能
- 轻量数据库SQLite存储梦想数据
- 接口：发布梦想、获取梦想列表、获取单条梦想
- 防重复快速提交（简单防抖校验）
- 无需登录，轻量化使用

### 6. 分享与传播
- 每个梦想卡片生成独立URL
- 可直接复制链接分享到社群
- 适配截图（干净卡片布局）

### 7. 兜底功能
- 404页面（像素风：时光机迷路啦）
- 表单前端校验（不能为空、不超过字数）
- 提交成功/失败提示

---

## 三、UI 规范（严格对齐 TRAE.ai 官网）
### 1. 配色
- 主背景：纯黑 / 深灰黑
- 主题色：TRAE 绿（像素荧光绿）
- 文字：白、浅灰
- 边框：像素风绿色虚线/实线
- 按钮：黑底绿边 + 绿色文字，hover变绿底黑字

### 2. 风格
- 像素风（pixel-style）
- 简约科技感
- 无圆角/小像素圆角
- 线条硬朗、复古游戏风

### 3. 元素
- 像素边框
- 像素图标
- 像素星星、像素飞船、像素电波
- 按钮点击有像素级动效

### 4. 排版
- 粗体标题
- 等宽字体优先
- 文字清晰、对比度高

---

## 四、前端页面结构（5个页面）
1. `index.html` —— 首页（入口）
2. `create.html` —— 发布梦想页
3. `card.html` —— 单个梦想卡片页
4. `wall.html` —— 梦想墙
5. `404.html` —— 404页面

## 五、后端接口（4个接口）
- `POST /api/dream` —— 发布梦想
- `GET /api/dreams` —— 获取梦想列表
- `GET /api/dream/:id` —— 获取单条梦想
- `GET /` —— 前端页面服务

## 六、数据库结构（SQLite）
表：`dreams`
- id (INTEGER PRIMARY KEY AUTOINCREMENT)
- nickname (TEXT) 昵称
- dream (TEXT) 童年梦想
- trae (TEXT) 用TRAE实现
- create_time (DATETIME) 时间

---

## 七、部署要求
- 托管平台：Vercel
- 架构：Node.js + Express 全栈托管
- 数据库：Sqlite（Vercel可直接支持）
- 无需额外环境，开箱部署
